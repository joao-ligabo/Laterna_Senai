## MELHORIA DO PROJETO

Como melhoria além dos requisitos obrigatórios, foi desenvolvido um sistema de personalização da iluminação.

A melhoria permite que o usuário controle:

Intensidade da luz;
Cor da luz.

Além disso, foi criado um contador que registra quantas vezes a lanterna foi ligada durante a execução da aplicação.

A variável utilizada para esse contador é:

_vezesLigada

Sempre que a lanterna passa para o estado ligado, o contador é incrementado.

Essa melhoria foi desenvolvida para tornar a aplicação mais interativa e permitir que o usuário tenha maior controle sobre o funcionamento da lanterna.
